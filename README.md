# 🌤️ Weather Dashboard

A responsive browser weather application that searches cities and displays current temperature, humidity, wind speed and weather conditions.

## Features

- City search with Enter-key support
- Live current weather data
- Temperature, humidity and wind speed
- Weather-condition icons
- Responsive mobile layout
- Accessible labels and status messages
- No application API key required

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Open-Meteo Geocoding API
- Open-Meteo Forecast API

## Run locally

This is a static site. Serve the project directory with any local HTTP server:

```bash
python -m http.server 8000
```

Open `http://localhost:8000`.

## Data and privacy

The application requests city and weather information from Open-Meteo directly from the browser. No application backend or user account is required.

## Deployment

The project can be deployed directly to Vercel, Netlify or GitHub Pages as a static site.
